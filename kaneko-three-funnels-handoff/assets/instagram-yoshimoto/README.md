## 実装上の注意

- 13枚をすべて原本素材として保持し、Spreadsheetの使用指示に従う。
- `6c890565...` は画像内に「セミナー不参加者へ」とある。未申込・日程不可ルートだけで使用し、申込済み・参加不明ルートへ送らない。入口別に分離できない場合は送信画像に設定しない。
- `6641105e...` は画像内に「セミナー参加者様へ」とある。本ファネルは参加／欠席を判定しないため、VSL完了者全体へ送らない。本画像のために新しい参加判定分岐を作らない。
- 画像内の「3日間限定」「20:00」などは実設定と一致する場合だけ公開する。不一致なら勝手に加工せず、差し替え承認を取る。
