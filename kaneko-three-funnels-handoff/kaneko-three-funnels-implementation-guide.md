## 4. 全媒体共通の排他制御

同時に有効な営業オファーは原則1つだけとする。上位状態が成立したら、条件除外だけでなく競合シナリオから読者を解除する。

優先順位:

1. `meeting_completed` / `sales_won` / `sales_stop`
2. `sales_in_progress` / `sales_next_meeting`
3. `roadmap_booked`
4. `offer_noshow_rebook_active`
5. `offer_consult_day_active`
6. `offer_vsl_active`
7. `seminar_*_registered`
8. `offer_seminar_active`
9. `openchat_invited`

必須の停止点:

- 特典キーワード受信: キーワード催促を停止。リンククリック有無は判定しない。
- Zoomサポート予約完了: サポート募集と下位オファーを停止し、予約リマインドだけ残す。
- セミナー申込完了: 未申込募集を全停止し、選択日程のリマインドへ移行。
- 「どちらの日程も合わない」初回クリック: セミナー募集を停止し、72時間VSLへ即移行。
- VSL視聴開始: 未視聴配信を停止。
- VSL視聴完了: 未視聴・途中視聴を停止し、面談案内へ移行。
- 個別面談予約完了: メインLINEと別の個別面談LINEの全競合オファーを停止し、面談リマインドだけ残す。
- 面談完了: ゴール。自動オプチャを含む全営業配信を停止。
- オプチャリンク初回クリック: 残りのオプチャ案内を停止。

## 5. セミナー募集の確定フロー

### 未申込者

1. 初回案内で日程①、日程②、「どちらの日程も合わない」の3ボタンを表示。
2. 第1日程の開催前まで未申込者へ催促。
3. 第1日程終了後、「次が最後の日程です」と第2日程を案内。
4. 第2日程の開催前まで未申込者へ催促。
5. 第2日程終了時点で未申込なら、確認ボタンを挟まず翌朝06:00から72時間VSL。

「どちらの日程も合わない」は、初回クリック時にセミナー募集を止め、「前回企画のダイジェスト版」として同じVSLを72時間公開する。初回クリック時刻を期限起点として固定し、再クリックで期限を延長しない。

### 申込者

選択した開催日程を保存し、その日程だけを基準にリマインドする。参加／欠席は次の入口条件にしない。

1. 本人が申し込んだセミナー開催日の翌朝06:00から個別ロードマップ作成会を案内。
2. 面談受付は同日23:59で実際にクローズ。
3. 面談未予約者は次の朝06:00から確認ボタンなしで72時間VSL。
4. 面談予約完了者は全オファーを停止し、面談リマインドだけを配信。

「セミナー開始15分後」や推定終了時刻を起点にしない。

### YouTube 3入口

## 7. 72時間VSL

すべての入口で、開始時刻を保存して厳密に72時間とする。

- 未視聴: 視聴開始を促す。
- 途中視聴: 続きの視聴を促す。視聴開始時に未視聴配信を止める。
- 視聴完了: 未視聴・途中視聴を止め、個別面談を案内する。
- 72時間終了: VSL配信を全停止。面談未予約・面談未実施ならオプチャへ。
- 面談予約完了: 72時間期限、VSL催促、オプチャ移行をすべて停止。

セミナー型では「再公開を希望しますか？」の確認シーケンスを挟まない。第2日程終了後、日程不可ボタン、セミナー申込者の面談受付終了後から、定義された起点で直接VSLへ入れる。

## 8. 個別面談・無断欠席・オプチャ

予約成立は予約ページクリックではなく予約完了イベントで判定する。個別面談用公式LINEは別アカウントのため、予約完了時にメインLINE側の読者を特定できる照合キーと停止アクションを実機で確認する。

面談無断欠席者:

1. 欠席確認直後にNS-01。
2. 翌日10:00にNS-02。
3. 翌日20:00にNS-03。
4. 3通後も未再予約なら、面談未実施者だけオプチャへ。

再予約完了時は3通とオプチャを停止する。事前キャンセル・日程変更は無断欠席回数に含めない。面談完了者はゴールとし、失注後のオプチャ案内は手動判断にする。

| 対象読者 | 処理 |
|---|---|
| YouTube/Instagramの旧ルート進行中 | 旧ルートを完走。新ルートへ一括移行しない |
| 2026-08-10以降のYouTube/Instagram新規 | 媒体タグ別の新ルートへ |
| Metaセミナー直行の新規 | 新ルートへ |
| Metaセミナー直行の既存・セミナー募集前 | 新しい2日程募集の現在地点へ |
| Metaセミナー直行の既存・申込済み | 選択日程リマインドまたは翌朝面談案内へ |
| Metaセミナー直行の既存・VSL進行中 | 現在の開始時刻・視聴状態を維持。期限をリセットしない |
| 面談予約済み | 移行対象外。面談リマインドのみ |
| 面談済み・成約・営業停止 | 全自動営業配信から除外 |

一括移行前に、状態別対象人数、移行元、移行先、停止するシナリオ、復旧用CSVを提示して承認を得る。

## 13. ロールバック

切替前に対象読者、所属シナリオ、ラベル、起点時刻をCSV保存する。問題発生時は新規流入を止め、新シナリオから対象読者を解除し、保存した読者状態を使って移行元または待避シナリオへ戻す。旧シナリオを削除せず、検証完了まで停止状態で保持する。
