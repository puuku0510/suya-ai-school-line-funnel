# UTAGE実装チェックリスト

## 1. 実装前に差し替える情報

- [ ] YouTube動画ごとの `[campaign]`、`[YouTube動画名]`、`[キーワード]`
- [ ] `[特典名]`、`[特典URL]`、`[特典で得られること]`
- [ ] 2種類の面談予約URL、Zoom URL、日程変更URL
- [ ] 本命セミナー日時、申込URL、参加URL、参加特典
- [ ] VSL URL、実公開終了日時、再公開URL
- [ ] オプチャURL、勉強会テーマ・日時・URL
- [ ] すべての送信元名が `すや` になっている

## 2. 最初に作る共通除外グループ

UTAGEで各シナリオの前に同じ除外条件を使えるよう、次のグループを作る。

1. `除外_営業完全停止`：`sales_won` または `sales_stop`
2. `除外_商談進行中`：面談予約済み、または `sales_next_meeting`
3. `除外_セミナー申込済み`：`seminar_main_registered`
4. `例外_欠席2回以上`：`consult_benefit_noshow_2plus`

成約時の一括処理:

- [ ] `sales_won` を付与
- [ ] 特典配布を除く全シナリオから解除
- [ ] 未送信予約メッセージを停止
- [ ] 顧客オンボーディングへ登録
- [ ] 新しい動画キーワードには特典だけ返す

## 3. YouTube動画ごとの入口テンプレート

動画が増えるたびに、以下だけ複製・差し替える。

- [ ] 媒体タグ `src_youtube_[campaign]`
- [ ] キーワード判定 `kw_[benefit]_received`
- [ ] 特典配布タグ `benefit_<benefit>_delivered`
- [ ] 特典URLクリック用タグ・アクションを作らない
- [ ] 登録10分後のキーワード未送信確認
- [ ] 正しいキーワード受信で未送信確認を止め、配布完了時点で既存 `特典クリック済み` シナリオへ登録
- [ ] 誤字・未登録語の `kw_unknown_manual` と管理者通知
- [ ] 既存友だちの再キーワード時に優先順位を再判定

既存友だちへ別特典を配るアクションは、次の順で条件分岐する。

1. 成約・営業停止 → 特典のみ
2. 面談予約・次回面談あり → 特典のみ
3. セミナー申込 → 特典のみ
4. その他 → 特典＋2日間面談募集

## 4. 特典活用サポート会

- [ ] 特典配布時点で2日間の実締切を保存
- [ ] 旧・特典リンク未クリック6通（SUP-A）を停止し、新規登録しない
- [ ] 特典配布完了で、実クリックを判定せず受取済み8通（SUP-B）へ登録
- [ ] 予約ページクリックで8通を解除し、10通へ移動
- [ ] 予約完了で8・10通をすべて解除
- [ ] 本文変更は承認済み2箇所だけ（`お受け取りいただきありがとうございます`／`特典をお受け取りくださり`）
- [ ] シート16・18・20行目相当の本文は変更しない
- [ ] 予約フォームは名前・メールアドレスだけ
- [ ] 完了ページと完了アクションに `consult_benefit_booked`
- [ ] 予約通知を営業担当者へ送る
- [ ] 5通の予約リマインドにZoom URLと日程変更URLを入れる
- [ ] 事前キャンセルでは無断欠席タグを付けない

面談の冒頭で必ず説明する内容:

> 今日は特典をどう使うかと、今の状況でどこから進めるかを一緒に整理します。お話を伺う中でお役に立てそうであれば、AIひとり起業スクールもご案内します。

## 5. 無断欠席・再予約

- [ ] 初回欠席で `consult_benefit_noshow_1`
- [ ] 2回目で `consult_benefit_noshow_2plus`
- [ ] 48時間3通の再予約シナリオ
- [ ] 再予約回数を制限しない
- [ ] 初回欠席後の最初の再予約中はセミナー募集を止める
- [ ] 2回目欠席以降はセミナー募集を止めず、再予約も受ける
- [ ] 事前キャンセル・日程変更時は欠席回数を増やさない

## 6. 営業結果入力

面談終了後に担当者へ4択の更新リンクまたは管理画面項目を出す。

- [ ] 成約 → `sales_won`
- [ ] 次回面談あり → `sales_next_meeting`
- [ ] 次回面談なし → `sales_no_next_meeting`
- [ ] 営業停止希望 → `sales_stop`

運用ルール:

- [ ] 次回面談が決まったら、その場で日時とZoomを登録
- [ ] `sales_next_meeting` 中はセミナーを含む下位募集を停止
- [ ] `sales_no_next_meeting` は24時間後に待機タグへ。次回開催の14日前から本命セミナー募集へ
- [ ] 面談を複数回持ち越す場合も、毎回4択のいずれかを更新
- [ ] 失注理由は任意メモ。自動配信の必須条件にしない

## 7. 本命ライブセミナー

- [ ] 開催ごとにキャンペーンIDを分ける
- [ ] 開催14日前に未申込者募集を開始
- [ ] D-14〜D-4の7通を登録
- [ ] D-3〜開始10分前の11通を登録
- [ ] 申込締切を開始3分前に設定
- [ ] 申込フォームで名前・メールアドレスを必須取得
- [ ] 申込完了で `seminar_main_registered`
- [ ] 申込完了で未申込者募集を解除
- [ ] LINEリマインド8通、メール4通を登録
- [ ] 登録日より前のリマインドはスキップ

参加判定:

- [ ] セミナー終盤で参加者だけが見られる特典ボタンまたはキーワードを提示
- [ ] クリック・キーワードで `seminar_main_attended` と `seminar_main_bonus_claimed`
- [ ] 判定不能者へ「欠席しました」と断定しない
- [ ] 判定不能者の翌日文は「見逃した方・復習したい方へ」

## 8. ロードマップ作成会

- [ ] セミナー終了時に特典と作成会を同時案内
- [ ] 3択アンケートを置かない
- [ ] 予約ページクリックで `consult_roadmap_page_clicked`
- [ ] 非クリックは終了時・翌日・翌々日の3通
- [ ] クリック未予約は2日10通
- [ ] 予約フォームは名前・メールアドレスだけ
- [ ] 予約完了で `consult_roadmap_booked`
- [ ] 予約完了でVSL・セミナー・オプチャ募集を停止
- [ ] ライブ参加後に予約しなかった人へVSLを重ねない

## 9. 3日限定VSL

- [ ] ライブ翌朝10:00に公開
- [ ] 3日目23:59にアクセスを閉じる
- [ ] 欠席・参加不明向けの枕詞を設定
- [ ] 未申込向けの枕詞を設定
- [ ] VSLリンククリックで `vsl_main_started`
- [ ] 視聴完了ボタン等で `vsl_main_completed`
- [ ] 未開封15通、一部視聴10通、完了後面談10通を登録
- [ ] 一部視聴者も3日目23:59で終了し、個別延長しない
- [ ] VSL内CTAをロードマップ作成会に一本化

再公開:

- [ ] 通常公開終了の翌日に希望確認3通
- [ ] `もう一度見たい` クリックで `vsl_main_reopen_requested`
- [ ] クリック時刻から24時間だけ再公開
- [ ] 再公開リマインド7通
- [ ] 2回目の再公開希望ボタンは出さない
- [ ] 再公開中に完了したら48時間面談募集
- [ ] 未完了・未転換ならオプチャへ

## 10. AIマニアの放課後

- [ ] 初回参加案内3日3通
- [ ] オプチャリンククリックで初回案内を停止
- [ ] 勉強会ごとに5通の募集・リマインド
- [ ] 本命セミナー募集と重なったら勉強会募集を停止
- [ ] 勉強会終了時にロードマップ作成会を案内
- [ ] 非クリック3通、クリック未予約10通
